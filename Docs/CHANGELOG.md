# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-24

### Added
- Initial project setup with CodeIgniter 4
- JWT authentication for admin users
- Device authentication for kiosk devices
- Multi-tenant architecture
- CRUD operations for:
  - Tenants
  - Locations
  - Kiosks
  - Users
  - Roles & Permissions
  - Content (Emotions, Contexts, Quran Verses, Hadiths)
  - Campaigns
  - Donations
- Reflection session management
- Print job management
- QR result generation
- Payment webhook handling
- Audit logging
- Reports (Overview, Sessions, Donations)
- Database migrations for all tables
- Complete API documentation
